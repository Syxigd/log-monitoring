## 2. 项目形态与启动入口

- 项目类型：Maven 多模块、模块化单体；根目录 `pom.xml` 管理 15 个模块。
- 唯一 Spring Boot 启动模块：`orchestrator`。
- 启动类：`orchestrator/src/main/java/com/ailog/orchestrator/OrchestratorApplication.java`。
- 组件扫描：`@SpringBootApplication(scanBasePackages = "com.ailog")`，其他模块作为库由 `orchestrator` 引入。
- 后端运行入口：`mvn spring-boot:run -pl orchestrator`。
- 前端目录：`ai-log-monitoring-ui/`，React 19 + Vite + TypeScript + Tailwind 4 + shadcn，包管理器为 pnpm。
- 前端运行/构建入口：`pnpm dev`、`pnpm build`。

## 8. 当前 WebSocket 跨域配置

文件：`dashboard/src/main/java/com/ailog/dashboard/config/WebSocketConfig.java`。

当前 `/ws/events` 处理器调用 `.setAllowedOrigins("*")`，表示允许任意 Origin。该设置不符合生产最小信任边界，后续应改为读取 `AILOG_DASHBOARD_ALLOWED_ORIGINS`，并对空值、逗号分隔多 Origin 和开发环境默认值做明确处理。
