# 多环境配置说明

## 配置分层

- `orchestrator/src/main/resources/application.yml`：公共配置、非敏感默认值和 `AILOG_` 环境变量引用。
- `orchestrator/src/main/resources/application-dev.yml`：开发环境非敏感差异。
- `orchestrator/src/main/resources/application-test.yml`：测试环境非敏感差异；测试凭据由运行环境注入。
- `orchestrator/src/main/resources/application-prod.yml`：生产环境非敏感差异；生产凭据由部署系统注入。
- `orchestrator/.env.example`：变量名和占位值示例；不得改成真实凭据。

## 激活方式

```text
SPRING_PROFILES_ACTIVE=dev
SPRING_PROFILES_ACTIVE=test
SPRING_PROFILES_ACTIVE=prod
```

Spring 先读取 `application.yml`，再用已激活 profile 的文件覆盖同名非敏感配置。环境变量通过 `${AILOG_*}` 显式绑定到 Spring 属性；不能依赖环境变量名称自动映射到 `spring.datasource.*`。

## 变量责任表

| 环境变量 | 绑定配置 | 敏感级别 | 默认/必填 | 责任人 |
|---|---|---|---|---|
| `AILOG_SERVER_PORT` | `server.port` | 非敏感 | `8080` | 开发/部署 |
| `AILOG_MYSQL_URL` | `spring.datasource.url` | 非敏感连接信息 | 必填 | 部署 |
| `AILOG_MYSQL_USERNAME` | `spring.datasource.username` | 敏感 | 必填 | 运维 |
| `AILOG_MYSQL_PASSWORD` | `spring.datasource.password` | 高敏感 | 必填 | 运维 |
| `AILOG_REDIS_HOST` | `spring.data.redis.host` | 非敏感连接信息 | 必填 | 部署 |
| `AILOG_REDIS_PORT` | `spring.data.redis.port` | 非敏感 | `6379` | 部署 |
| `AILOG_REDIS_PASSWORD` | `spring.data.redis.password` | 高敏感 | 必填 | 运维 |
| `AILOG_REDIS_DATABASE` | `spring.data.redis.database` | 非敏感 | `0` | 开发/部署 |
| `AILOG_ROCKETMQ_NAME_SERVER` | `rocketmq.name-server` | 非敏感连接信息 | 必填 | 部署 |
| `AILOG_RUSTFS_ENDPOINT` | `rustfs.endpoint` | 非敏感连接信息 | 必填 | 部署 |
| `AILOG_RUSTFS_ACCESS_KEY` | `rustfs.access-key` | 高敏感 | 必填 | 运维 |
| `AILOG_RUSTFS_SECRET_KEY` | `rustfs.secret-key` | 高敏感 | 必填 | 运维 |
| `AILOG_RUSTFS_BUCKET` | `rustfs.bucket` | 非敏感 | 必填 | 运维/部署 |
| `AILOG_MCP_DOCKER_RESTART_ENABLED` | `mcp.docker.restart-enabled` | 安全开关 | `false` | 平台负责人 |
| `AILOG_MCP_RUSTFS_DELETE_ENABLED` | `mcp.rustfs.delete-enabled` | 安全开关 | `false` | 平台负责人 |
| `AILOG_DASHBOARD_ALLOWED_ORIGINS` | `dashboard.allowed-origins` | 安全策略 | 本地 `http://localhost:5173` | 平台负责人 |

## 生产约束

生产环境必须由部署系统注入全部标记为“必填”的变量。基础配置对这些变量不提供危险默认值，变量缺失时 Spring 启动失败。生产禁止把 `.env`、密码、Access Key 或 Secret Key 提交到 Git；真实凭据由密钥管理或部署系统托管。

本说明只完成代码侧变量契约，不代表 MySQL、Redis、RustFS 的旧凭据已经失效。凭据轮换按《第一阶段凭据轮换清单》执行并由运维保留审计记录。
